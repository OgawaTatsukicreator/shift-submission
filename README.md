# シフト提出・希望確認システム

## 概要

このプロジェクトは、従業員がスマートフォンから月間のシフト希望とPT申請を提出し、自分の提出内容を確認するための Google Apps Script（GAS）アプリです。従業員IDによるログイン、初回登録、パスワード変更、提出済み希望の確認に対応しています。店長や管理者は、関連する Google スプレッドシートでシフトの調整と確定反映を行います。

現在の従業員向け画面に**確定シフトの表示はありません**。実際に動く画面は `GasApp.html`、サーバー処理は `Code.gs` です。`index.html`・`styles.css`・`app.js` は旧画面の利用停止案内です。

詳しい要件は [要件定義書](.docx/RDD.md)、設計と既知の未達事項は [設計書](.docx/Design.md) を参照してください。以前の詳細な README は [記録](.docx/README-previous.md) に保存しています。

## インストール

Node.js や npm のインストールは不要です。Google アカウントと、用途別の Google スプレッドシート（DB管理用・全体確認用・エリア確認用・提出ログ用）を用意してください。DB管理用スプレッドシートから Apps Script プロジェクトを開きます。

1. `Code.gs` 冒頭の `ADMIN_SPREADSHEET_ID`、`OVERALL_SPREADSHEET_ID`、`AREA_SPREADSHEET_ID`、`SUBMISSION_LOG_SPREADSHEET_ID` を、用意した各スプレッドシートの ID に合わせます。既存環境の ID を変更する場合は、先に管理者へ確認してください。
2. DB管理用スプレッドシートの「拡張機能」→「Apps Script」で開いたエディタに `Code.gs` を配置します。HTML ファイルを `GasApp` という名前で追加し、`GasApp.html` の内容を貼り付けます。
3. スクリプト所有者がエディタで `authorizeOnce` を選んで実行し、求められる権限を承認します。この処理は管理者設定、必要なシート、日次メンテナンストリガーを準備します。
4. DB管理用スプレッドシートの `エリアマスタ`、`店舗マスタ`、`従業員マスタ`、`従業員店舗設定` に運用データを入力します。必要に応じて `管理対象ファイル` を設定します。
5. Apps Script の「デプロイ」→「新しいデプロイ」から「ウェブアプリ」を選びます。実行ユーザーは「自分」に設定し、アクセス範囲を運用に合わせて指定してデプロイします。

認証用シートと提出ログへのアクセス権は管理者に限定してください。実スプレッドシートとの結合動作や本番デプロイは、このリポジトリだけでは確認できません。

## 使い方

1. 管理者は DB管理用スプレッドシートの `従業員マスタ` に、利用者の従業員IDを有効な状態で登録します。
2. 従業員はウェブアプリURLを開き、「初めての方」から従業員IDを入力し、パスワードを設定します。次回からは従業員IDとパスワードでログインします。
3. 「希望提出」で対象月の各日の勤務可否や時間を入力して提出します。「希望確認」で提出済み内容を確認し、必要に応じて「PT申請」を使います。

「希望提出」と「PT申請」は、ログイン時に `従業員マスタ` の主所属エリア・主所属店舗を初期選択します。エリアを変更すると、そのエリアの全有効店舗から勤務先を選べます。保存済みの下書きがある場合は、その下書きのエリア・店舗を復元します。勤務先を変更しても、従業員マスタの主所属は変更されません。

管理者が初期設定で実行する Apps Script 関数の例です。エディタ上で実行対象として選びます。

```javascript
authorizeOnce();
```

`GasApp.html` は `google.script.run` を使って `Code.gs` を呼び出します。ローカルの `index.html` を開いても希望は提出できません。

## 運用

1. 店舗・従業員情報や店休日は、DB管理用スプレッドシートのマスタと `業務設定` で管理します。管理者は必要に応じて `シフト制作` メニューで提出内容の表示再生成や確定反映を行います。
2. 変更を提案する場合は、このリポジトリをフォークして作業用ブランチを作り、変更をコミットします。
3. 画面変更は `GasApp.html`、GAS処理の変更は `Code.gs` を確認し、対象機能を検証してからプルリクエストを送信します。設計や運用手順を変えた場合は `.docx/` の文書も更新します。

本番導入前に、スプレッドシートの共有権限、Apps Script のデプロイ設定、スマートフォン実機での操作を確認してください。既知の制約と検証状況は [設計書](.docx/Design.md) に記載しています。
